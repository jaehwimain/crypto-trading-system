### Phase 2: 회귀분석 모듈 (1주)
**목표:** 과거 8년 데이터에서 초기 파라미터 자동 계산

**핵심 원리:**

$$\text{수익률} = w_1 \times \text{지표}_1 + w_2 \times \text{지표}_2 + \cdots + w_{30} \times \text{지표}_{30}$$

회귀분석을 통해 최적 가중치 $w_1, w_2, \ldots, w_{30}$ 도출

**파라미터 구성 (코인당):**
- 30개 기술지표 가중치
- 진입점 임계값 (예: 점수 >= 65점일 때 진입)
- 손절가 비율 (예: -2%)
- 익절가 비율 (예: +5%)
- 포지션 크기 (예: 자산의 10%)
- 최대 포지션 개수 (예: 5개)

**산출물:**
- `RegressionOptimizer` 클래스
- `initial_params.json` (50개 코인별 최적 가중치)
- `regression_analysis_report.json` (각 지표의 중요도 순위)

**필수 구현:**
1. 과거 데이터 전처리
   - 결측치 처리
   - 정규화 (모든 지표 0~100 범위)
   - 이상치 제거

2. 상관계수 계산
   - 각 지표와 수익률의 상관관계
   - Pearson 상관계수 또는 Spearman 순위 상관계수

3. 회귀계수 도출
   - 선형 회귀 (linear regression) 사용
   - scikit-learn 또는 numpy.polyfit 활용

4. 가중치 최적화
   - 음수 가중치 제거 (음수 영향 지표 무시)
   - 합계 = 1.0으로 정규화
   - 상위 15개 지표만 유지 (노이즈 제거)

**체크리스트:**

### Phase 4: 강화학습 모듈 (3주)
**목표:** 실시간 모의투자에서 Q-Learning으로 자동 조정

**핵심 원리:**

$$Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max Q(s', a') - Q(s, a)]$$

- $s$: 현재 상태 (30개 지표)
- $a$: 행동 (진입 또는 스킵)
- $r$: 즉시 보상 (거래 수익률)
- $\gamma$: 할인 계수 (0.9)
- $\alpha$: 학습률 (0.01)

**상태 공간 (State Space):**
- 30개 기술지표 각각 5단계로 이산화
  - 예: RSI = [0, 20), [20, 40), [40, 60), [60, 80), [80, 100]
- 상태 = 지표 5단계 조합
- 총 상태 수 ≈ $5^{30}$ (너무 크므로 핵심 지표만 선별)
  - **핵심 지표 10개만 사용** → 상태 수 = $5^{10}$ ≈ 977만 (관리 가능)

**행동 공간 (Action Space):**
- 0: 진입하지 않음
- 1: 진입 (포지션 크기 10%)
- 2: 진입 (포지션 크기 15%)
- 3: 진입 (포지션 크기 20%)

**보상 함수 (Reward Function):**
```python
def calculate_reward(entry_price, current_price, exit_price):
    profit_pct = (exit_price - entry_price) / entry_price
    if profit_pct > 0:
        reward = min(profit_pct * 100, 10)  # 상한선 10
    else:
        reward = max(profit_pct * 100, -10)  # 하한선 -10
    return reward
